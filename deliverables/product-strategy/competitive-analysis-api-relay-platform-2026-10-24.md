### 1.2 结论（拖累分析）
- **唯一满分项**：**错误归因 / 降损**——这是 api-relay 的护城河窄点，须守住。
- **分差最大的三项**（即行动清单依据）：**多租户（24）→ 计费账务（20）→ 协议兼容/SDK（16）**；换任何一套权重，此短板排序**稳定**。
- **合规红线**：NewAPI 采用 AGPL-3.0 + Section 7（附加署名/UI 可见项目链接），**只要跑成面向用户的服务就须提供完整对应源码** → 直接否决"fork NewAPI 做闭源自有品牌中转站"路径（与 design-proto「不做 fork」一致）。
- **三条最关键的差异化机会**：见零件 §4.5；核心是**把"错误可执行化"做成对外契约**（failure_reason × quick_action 词表公开），而非仅内部能力。

### 1.3 Battle Card 要点
面对 LiteLLM（生态强）/ OpenRouter（聚合大）/ NewAPI（迭代快、许可受限）时，我方主张：**"同价纯管道 + 错误可执行 + 可自证透明"** 三位一体；攻其"错误语义丢失/闭源受限"，防其"生态与文档厚度"。

## 2. 「降损价值可对账」数据方案（数据分析师）

### 2.1 指标体系（9 项主指标 + 2 项护栏）
主指标：归因投递率、自动恢复数、无效重试数（60s 同 payload）、预检拦截数、预检降级放行数、降损层自身开销占比、prompt cache 命中 token、**无效 token 成本节省额（WTCS）**、平均修复时长/人工介入次数下降。
护栏：`relay_error = 0`、预检降级放行 `PD = 0`。

### 2.2 最关键 3 个可对账指标（口径与公式）
| 指标 | 公式 | 数据来源 |
|---|---|---|
| **无效 token 成本节省额 WTCS（¥/年）** | `[WastedCost_C − WastedCost_E] + [CacheSaved_E − CacheSaved_C] + [RetrySaved]`；其中 `WastedCost = Σ{失败且上游已返回 usage}(prompt×p_in + completion×p_out)/1e6` | `relay.cost.total` / `relay.reduction.wasted_tokens` |
| **自动恢复数 ARR** | `Σ relay.reduction.recovered_requests`（outcome=success 且 steps 含 retry） | relay 度量 |
| **无效重试数 DR** | `Σ relay.retries.duplicate`（60s 窗口同 (keyId, payloadHash, model) 第 2 次起；**单副本口径，多副本低估**） | relay 度量 |

> **对账承诺**：任一对外数字都可用 `原始计数 × 单价 × 公式` 复算，客户能自己乘出来。

### 2.3 实验设计
- **主设计**：同层（standard/pro）**请求级随机 A/B**——对照=降损 off（纯管道），实验=全降损；显著性放请求级。
- **样本量**：α=0.05 双侧、power=0.80、基线 p₁=5%、主终点相对降 20% → **每组 ≈6,750 请求、合计 ≈13,500 请求**（降幅 10% 需 ≈28,400/组；30% 需 ≈2,840/组）。
- **窗口**：建议 **4 周**（1 周洗牌 + 3 周观测），最低 2 周（降级为方向性）。
- **成功判据**：主终点"无效重试率相对降 ≥20% 且 p<0.05"；护栏 OH≤0.1%·p99≤2ms、A 类误拦=0、`relay_error=0`、`PD=0`、成功率非劣（−0.5pp）。
- **客户级**：早期客户数不足 → 仅用 bootstrap CI（1,000 次重采样，BCa）描述，**不签发显著性结论**。

### 2.4 从基线到定价（5 阶段）
`S0 埋点就绪 → S1 基线期(2–4周) → S2 价值量化(单客户年节省额¥) → S3 溢价反推(溢价=WTCS×捕获率−我方成本) → S4 定价区间与试点`。
**结论**：降损节省额属**个位数百分比**，**不足以单独支撑高订阅价** → **Pro 应以「额度 + SLA + 可观测与可诊断」为主锚，"可对账节省额"作价值证明与续费依据**。

### 2.5 口径冲突待统一
`README §7.3`「开销占比应<0.1%」 vs `research/03 M10`「ratio>3% 须自动降级」→ 建议区分**对外承诺 0.1%** 与**工程熔断线 3%**。
