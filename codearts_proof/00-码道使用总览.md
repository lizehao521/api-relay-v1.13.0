**关键产出**：

- **多方法交叉验证**：推翻「22 端口 sshd 未运行」的错误结论（Node `net.connect` 误报 → .NET TcpClient / curl / 真实握手确认为 OPEN）；
- **CRLF 缺陷定位**：Windows 工作副本导致 `.env` 尾部 `\r` → `KEY_MISMATCH`，在 `install-server.sh` / `pack-local.sh` 双向归一化；并识破 Git Bash `grep -c $'\r'` 恒为 0 的计量陷阱，改用字节级双方法复核；
- **模型可用性预检**：发现 `qwen3.8-flash-next` 仅存在于 env 示例、必定 404，改用实测可用的 `glm-5.3`；
- **CSP 白屏根因**：`upgrade-insecure-requests` 把子资源升级到不存在的 https，headless Edge + netlog 抓到 `SSL_HANDSHAKE_ERROR -107`；修复后渲染 DOM 2,199 → 26,416 字节。
