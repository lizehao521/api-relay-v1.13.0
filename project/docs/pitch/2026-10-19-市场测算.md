# api-relay 赛道生命周期定位与 TAM/SAM/SOM 测算

> 出具日期：2026-10-19 ｜ 方法：外部报告锚点 + 自下而上交叉验证 ｜ 受众：投资人 + 技术决策者
> 证据等级：`[E1]` 源码 ｜ `[E2]` GitHub 元数据 ｜ `[E3]` 厂商官方文档 ｜ **`[E4]` 第三方报告/公开报道**（均为外推，需在尽调中复核）
> **使用警告**：本测算中"LLM Gateway"这一品类**定义尚未收敛**，不同报告的市场规模差距达 **180 倍**（见 §1.3）。任何单一数字都不可作为决策依据，必须连同口径一起读。

## 1. 市场定义（先说分母，再谈规模）

> 教训来自一次公开批评：所有人都在引用"OpenRouter 占市场 2%"这个数，但没人算过那个分母。**分母换了，结论就反了。**

### 1.1 三个候选口径

| 口径 | 定义 | 是否计入 token 消费 | 是否计入平台型捆绑 |
|---|---|---|---|
| **A. 纯 Gateway 软件** | 只算 AI Gateway / LLM Proxy 产品的订阅与 license | ❌ 排除 | ❌ 排除 |
| **B. 治理层订阅 + 计量费** | 含 API 管理平台的网关模块、按请求/日志计量费、credit 抽成 | ❌ 排除 | ✅ 计入 |
| **C. 经网关的**治理支出**（GMV）** | 所有流经网关的 inference 花费 | ✅ 计入 | ✅ 计入 |

**api-relay 应同时讲 A/B 作为"收入 TAM"，讲 C 作为"叙事 TAM"**——这是路演与尽调都不会翻车的唯一讲法。

### 1.2 外部锚点（`[E4]`）

| 来源 | 口径 | 2025 | 2026 | 远期 | CAGR |
|---|---|---|---|---|---|
| QY Research / LP Information（窄口径） | A | **$18.59M** | — | $270M（2032） | 46.8% |
| The Business Research Company | B（Gateways） | $2.18B | **$2.76B** | $7.21B（2030） | 26.9–27.1% |
| The Business Research Company | B（Platform） | $3.34B | **$4.23B** | $11.01B（2030） | 26.7% |
| 行业双路法报告 | B | **$820M**（band $660M–$1,020M） | — | $7.30B（2034） | 27.5% |

### 1.3 必须承认的口径分歧

窄口径（$18.59M）与宽口径（$3.34B）相差 **180 倍**。原因：多数厂商的网关能力**以平台模块、免费开发者功能或企业附加包的形式存在，没有独立披露收入**（该报告原文即如此说明）。因此：

- **本测算以"双路法"的 $820M（2025）为基准**——它是唯一同时给出 top-down 与 bottom-up 两条独立路径、并做了交叉验证的口径；
- 其余口径作为**区间上下界**，用于压力测试。

## 2. 关键可比公司：OpenRouter（唯一的公开增长锚点）

api-relay 与 OpenRouter 的**商业模式不同**（前者软件/服务，后者抽成），但它提供了**唯一可用的增速与估值锚**。

| 时点 | ARR / 指标 | 来源 |
|---|---|---|
| 2025 年末 | **$19M** ARR | `[E4]` Sacra |
| 2026-03 | **$50M** ARR（YoY +1,840%）；3T+ tokens/day、8M 开发者 | `[E4]` Sacra |
| 2026-07 | **$140M** ARR（近 4 个月 MoM +29%） | `[E4]` Sacra |
| 2026-08 | **$160M** ARR（MoM ~14%） | `[E4]` Sacra |
| 2026-10 | GMV ~**$1.2B** annualized；blended $0.66/M tokens | `[E4]` CodeSOTA |
| **商业模式** | **take rate ≈ 5%**（对经手 inference 花费抽成） | `[E4]` Sacra |
| **估值锚** | $113M Series B @ **$1.3B**（≈26x forward revenue，CapitalG）；**传闻 Stripe 洽谈以 ~$10B（≈71x ARR）收购** | `[E4]` Sacra（传闻需复核） |

### 2.1 三条可直接用于路演的"为什么是现在"

1. **安全事件把"自建网关"的风险实证了**：2026-03 针对 **LiteLLM 的供应链攻击**，据报道外泄 1TB 私有源码、3TB 客户数据与下游 API 密钥，波及 Mercor 等客户。→ 需求从"方便接入"转向"**可信的托管/可自建控制层**"。
2. **成本优化成为主旋律**：中国开源模型从 2025 年中的 ~2% 升至 2026-08 OpenRouter 用量的 **50%+**（token 量 3 倍增长，单 token 货币化下降 ~60%）。→ "让便宜模型跑得稳"比"接更多模型"更值钱。
3. **路由已成为标准基础设施**：Vercel（2025-08）、Merge（2026-04）、Cursor、Databricks、Ramp、Kong 均上路由能力；Helicone 于 2026-03 被 Mintlify 收购。→ 赛道被确认，但也**正在被平台捆绑**。

## 3. 赛道生命周期定位

**结论：LLM Gateway 品类处于「期望膨胀期后段 → 幻灭低谷」的过渡区；但"错误可执行化"这一子能力仍在「创新触发期」。**

| 判据 | 观察 | 指向 |
|---|---|---|
| 厂商数量 | Kong / Cloudflare / Vercel / Merge / Portkey / Helicone / LiteLLM / OpenRouter 均在场 | 已过萌芽 |
| 多模式产品化 | 报告称市场为"multiple models"与 agent 流量驱动 | 成长早期 |
| **货币化落后于用量** | 报告原文：**"Revenue grows more slowly than tokens because vendors give core features away, bundle gateways into API management tiers and compete with open-source software"** | **★ 幻灭低谷特征** |
| 免费/开源挤压 | LiteLLM（MIT，免费）、NewAPI（AGPL）| 溢价空间被压 |
| 资本定价 | OpenRouter $1.3B（26x forward rev）、Stripe ~$10B 传闻 | 资本仍给高估值 |

- **采用曲线**：开发者侧已进入**早期大众**（8M 开发者）；**企业采购侧仍在早期采用者**（全球仅 28% 的 AI 使用型大企业部署了专用网关）。
- **置信度：中**。Gartner 确有 "Market Overview for AI Gateways" 文档（`[E4]` gartner.com/en/documents/7855181），但**本测算未取得其量化象限定位**，上表为基于公开证据的推断，非 Gartner 原文引用。

> **对路演的含义**：不能说"这是个高速成长的蓝海"——它**成长快但货币化难**。正确说法是："**一个已被验证、正在被平台捆绑的赛道；硬币的另一面是，错误路径这一格仍无人做。**"

## 4. TAM / SAM / SOM

### 4.1 口径 A+B（收入 TAM，保守可辩护）

**TAM（全球 LLM Gateway 软件/治理层收入，2026）≈ $1.1B**
- 基准：$820M（2025）× 1.275 = **$1.05B**（双路法 CAGR 27.5%）
- 区间：**$0.66B – $2.76B**（下界为双路法 band，上界为 TBRC 宽口径）

**SAM（亚太 × 需要私有化/自建 × Agent 密集）≈ $60M–$75M**
- 全球 gateway 收入 NA 占 46%，**APAC 增长最快（29.8%/年）**，本测算取 APAC 份额 **20%** → $1.05B × 20% ≈ **$210M**
- 其中"**拒绝 AGPL（NewAPI）、拒绝闭源托管（OpenRouter/Cloudflare）、必须自建**"的细分，按 **30%** 估 → **≈ $63M**
- 置信度：**中低**（APAC 份额与"自建偏好比例"均为推断）

**SOM（3 年可获取）≈ $0.2M – $0.7M ARR**
- 自下而上：中国 AI 使用型大企业 ≈ 146,000（全球）× 15% ≈ **22,000 家** → 有专用网关 28% ≈ **6,160 家** → 需要"私有化 + 错误可诊断 + 愿付费" 20% ≈ **1,232 家** → ARPU **$6,000/年** → **SAM ≈ $7.4M/年**
- SOM（3 年拿下 SAM 的 3–8%）→ **$0.22M – $0.59M ARR**，约 **35–100 家付费客户**

### 4.2 口径 C（叙事 TAM，面向融资）

- 全球 inference 收入 ≈ **$130B**（区间 $100B–$150B）；其中经网关治理的支出 ≈ **$7.4B**（2025）
- APAC 部分 ≈ $7.4B × 20% = **$1.48B**
- 若按 OpenRouter 式 **5% take rate**，且 api-relay 能拿下 APAC 治理支出的 **1–3%** → **收入潜力 $0.7M–$2.2M/年**
- 若要达到 $10M ARR，需要经手 GMV ≈ **$200M/年**（5% take）——**相当于 OpenRouter 2026 年中 GMV 的 ~17%**

### 4.3 交叉验证

| 路径 | 结果 | 与基准偏差 |
|---|---|---|
| Top-down（口径 A+B） | SAM ≈ $63M | — |
| Bottom-up（企业数 × ARPU） | SAM ≈ $7.4M | **-88%** |
| **偏差 > 3x → 按方法论必须重新审视假设** | | |

**偏差原因（诚实拆解）**：top-down 的 $63M 里包含了"平台型厂商捆绑收入"（Cloudflare/Kong 的模块），这部分 api-relay **根本拿不到**。剔除后与 bottom-up 的 $7.4M 量级一致。

> **结论：api-relay 的真实 SAM ≈ $7M–$15M/年（亚太、自建偏好、Agent 密集细分），量级为千万美元级，不是十亿美元级。**

## 5. 战略结论：两条叙事，二选一

| | **叙事 A：小而美的私有化中间件** | **叙事 B：亚太可信托管中转层** |
|---|---|---|
| 对标 | 无直接对标（工具生意） | OpenRouter |
| 收入模式 | license / 订阅（$6K–$30K/年/客户） | take rate（3–5%）+ Pro 订阅 |
| 可寻址 | SAM ≈ $7M–$15M | 治理支出 $1.48B（APAC） |
| 3 年上限 | <$1M ARR | $5M–$20M ARR（需 GMV $100M–$400M） |
| 适合 | bootstrap，不需要融资 | **VC 叙事** |
| 核心前提 | 无 | **必须成为"托管可信层"**（LiteLLM 攻击事件是催化剂） |

**给路演的直接建议**：
- 若目标是**融资** → **必须讲叙事 B**，并把 **2026-03 LiteLLM 供应链攻击**作为"为什么是现在"的第一论据（安全事件实证了自建风险 → 托管可信层需求）。
- 但**绝不能把 TAM 说成 $4B/$11B**——那是"被平台捆绑的收入"，尽调时会当场被拆。正确话术：**"我们的 SAM 是千万美元级的细分，但它是 OpenRouter 式的千万 GMV 抽成入口。"**
