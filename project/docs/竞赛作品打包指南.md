# 竞赛作品打包指南（v1.10.0）

本文件说明**提交压缩包**应包含的内容、需排除的项、打包方式与上传注意事项。

## 包内结构

```
├── project/              完整工程源码（含 docs/、dist/、dist-admin/；不含 node_modules/、data/）
├── ppt/                  作品介绍 PDF 与答辩文稿
├── video/                演示视频 + 在线链接 + 分镜脚本
├── codearts_proof/       码道（CodeArts）使用痕迹：总览 + Prompt 存档 + 18 张截图
├── readme/               码道应用总结 / 开源组件说明 / 线上部署说明 / systemd unit
├── deliverables/         产品与竞品策略分析
├── design-proto/         交互原型与产出物
└── SUBMISSION-README.md  包内说明 + 复现步骤
```

## 必交材料对应（赛题要求 → 包内）

| 赛题要求 | 包内 |
|---|---|
| 程序代码（压缩包） | `project/` |
| 整体介绍 PPT | `ppt/` |
| 演示视频（或在线演示环境） | `video/`（含在线直链）；线上实例见 `readme/README.md` |
| 码道（CodeArts）使用痕迹 | `codearts_proof/` |
| 环境依赖说明 / 部署步骤 / 运行指南 | `readme/` + `SUBMISSION-README.md` + `project/README.md` |

## 有意排除（不得入包）

- `node_modules/`：依赖由 `package.json` / `package-lock.json` 声明，安装即可。
- `data/`：运行时数据库（`relay.db` / `kb.db` 及 WAL），首次运行自动创建。
- 敏感与内部文件：`api-relay-root-pwd.txt`（含口令）、`.arts/`、`.codeartsdoer/`、`.opencode/`、
  `.resultverify/`、`.merkle-snapshot.json`、`patch_judge.py`、`.git/`。

## 打包方式（可复现）

```powershell
$stage = "$env:TEMP\api-relay-stage\api-relay-v1.10.0"
New-Item -ItemType Directory -Path $stage -Force | Out-Null
robocopy project        "$stage\project"        /E /XD node_modules data .git
robocopy codearts_proof "$stage\codearts_proof" /E
robocopy deliverables   "$stage\deliverables"   /E
robocopy design-proto   "$stage\design-proto"   /E
robocopy ppt            "$stage\ppt"            /E
robocopy readme         "$stage\readme"         /E
robocopy video          "$stage\video"          /E
tar -a -cf "$env:USERPROFILE\Desktop\api-relay-v1.10.0-submission.zip" -C $stage `
  project codearts_proof deliverables design-proto ppt readme video SUBMISSION-README.md
```

> 打包前务必先 `npm run build`，确保包内 `dist/`、`dist-admin/` 与源码同批次（否则评审用旧产物运行会得到旧行为）。

## 上传注意事项

- **体积**：目标 ≤ 200MB；本包约 21MB，余量充足。
- **文件名**：部分平台限制字符集（`A-Z a-z 0-9 - _ .`）——本包名 `api-relay-v1.10.0-submission.zip` 为纯 ASCII，安全。
- **结构**：解压即得上述 8 项，无多余一层嵌套、无 `./` 前缀。
- **迭代节奏**：每日通常限提交 1 次（可多次迭代，取最新/最高版本）；迭代前先跑 `npm test`（当前 379 项全绿）与 `npm run build`。
