## 实际录像内容（与实拍一致，不超卖）

**前段 · 底座（api-relay, :8787）**：`/judge` 评委页 → 管理员登录 → 总览 → 指标 → 上游 → 请求账本 → 租户 → 套餐与账单 → Agent → 总览。

**中段 · 工作台（CodeLens, :8788）**：免密 token 直链进入 → 新建会话 → 示例任务「用计算工具算 (1234.5×87)/13，并说明每一步」→ 流式输出 → 运行检视器 → 工具面板（3 次工具调用可见）。该链路实测：**首 token ≈ 4.7 秒，工具 3 次，全程 ≈ 41 秒**，模型 `custom / glm-5.3`（经底座原生 function calling）。视频中出现的「成本超阈值」风险提示是**四道预算闸生效**的实拍画面，非故障。

**尾段 · 串联证据**：切回底座**请求账本**（工作台刚才的每次调用都在账内）→ `/judge` 定格收尾。

## 录制方式（可复现 · 本机 CDP 录制）

录制环境为 **开发机本机**（非服务器）：Microsoft Edge（headless `new`）+ `puppeteer-core` 直连**线上公网页面**，经 CDP `Page.screencast` 采帧（1600×900 / JPEG q72），帧带真实时间戳，`ffmpeg -f concat` 按帧间时长合成，三段分别录制后拼接、整体 1.09× 变速对齐 3 分钟以内。

关键技术点（踩坑记录，均在录制脚本注释中）：

1. **就绪断言先行**：录前逐页断言（管理后台 14 页签逐一点击可达、CodeLens `#root` 渲染体积阈值），杜绝录到白屏/错误态——CodeLens 当初 CSP 白屏的教训。
2. **跨文档导航后必须重启 screencast**（`page.goto` 后 CDP 停止推帧），帧序号与时间基准跨重启连续。
3. **帧回调必须立即 ack**、画面数据先驻内存再统一异步落盘——同步写盘会把帧率压到 1fps 以下（CDP 收到 ack 前不推下一帧）。
4. screencast 仅画面变化时推帧：剧本内置小幅持续滚动，避免定格。
5. 演示全程使用免密 token 直链与本机自动化登录（凭据不入库、不回显）。
