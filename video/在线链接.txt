## 录制说明

- **录制环境**：服务器端无人值守录制（Ubuntu + Xvfb 虚拟显示 1600×900 + Google Chrome + ffmpeg x11grab）。
- **录制对象**：**在线看板**（管理面板）真实运行数据，按脚本自动切换页签：
  **总览 → 指标 → 上游 → 请求账本 → 租户 → 套餐与账单 → Agent → 总览**。
- **登录方式**：本次以**管理员（owner）账号**登录录制，以展示租户/计费页（viewer 账号无 `tenants.admin`，看不到租户页）；
  评委现场经 `judge` 页进入的是**只读看板**。
- **画面内容**：作品部署实例的实时读数——请求量/错误率、失败归因分布、降损层收益、上游健康与熔断、
  请求账本轨迹、租户与角色矩阵、套餐目录与账单/对账、内部 Agent 巡检记录与指标。
- 录制脚本：`/root/recorder/`（`record.js` + `run-record.sh`，采用"页面就绪后再开录"以避免片头白屏）；
  本次改造：页签计划加入 `tenants` / `billing`，登录账号切为 admin（原脚本已备份为 `record.js.bak-*` / `run-record.sh.bak-*`）。
