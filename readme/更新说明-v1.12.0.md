## 5. 兼容与边界

- 链名即客户端请求的 `model` 名。改中文后，客户端要写 `model: "旗舰"`（写 `flagship` 会 404）。
- 本配置的 `clients` 未设 `allowedModels` 白名单，无需同步改白名单。
- 面板「运维」页的「模型别名」行渲染链名（`旗舰 → qwen3.8-max → …`），改配置后需**重启网关**再刷新。
