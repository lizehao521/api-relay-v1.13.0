# 环境依赖说明与一键安装（readme/）

> 对应《作品提交规范》readme 要求第 1 项：**环境依赖说明与一键安装脚本**。
> 版本：**v1.13.0** ｜ 适配：Linux / macOS（bash）与 Windows（PowerShell）

---

## 1. 环境依赖

| 依赖 | 版本要求 | 说明 |
|---|---|---|
| **Node.js** | **≥ 22.5.0** | 必须：后端使用内置 `node:sqlite`，低版本会报 `node:sqlite` 不存在 |
| npm | ≥ 10（随 Node 附带） | 仅用于安装**构建期**依赖 |
| 磁盘 | ≥ 500 MB | 源码 + 构建产物 + 运行库（SQLite/KB） |
| 网络 | 出站 HTTPS（生产接真实上游） | **Demo/Mock 模式完全离线**，无需任何密钥 |
| 运行时依赖 | **0 个**（底座） | 仅 `node:http` / `node:crypto` / `node:sqlite` + 全局 `fetch`；供应链攻击面为零 |
| CodeLens 构建 | Node ≥ 22.5 + npm | 工作台前后端各自 `npm install`（React 19 / Express 5 等构建期与运行期依赖） |
| 反向代理（可选） | nginx ≥ 1.18 | 组合方案对外入口 `8788`，含 Basic Auth 与 CSP 覆盖 |

> 可选：`tsx`、`typescript`、`vite`（devDependencies，仅构建期；不参与运行时）。
> **底座零运行时依赖，CodeLens 不是**——这是两层各自的取舍：底座追求最小攻击面，工作台追求开发效率。

## 2. 一键安装脚本

| 平台 | 脚本 | 运行方式（均在**作品包根目录**执行） |
|---|---|---|
| Linux / macOS | `readme/install.sh` | `bash readme/install.sh` |
| Windows | `readme/install.ps1` | `powershell -ExecutionPolicy Bypass -File readme\install.ps1` |

脚本做的事：① 校验 Node ≥ 22.5 → ② 安装后端与前端构建依赖 → ③ `npm run build` 产出 `dist/` 与 `dist-admin/`。

### 2.1 `readme/install.sh`（摘要）

```bash
#!/usr/bin/env bash
set -euo pipefail
cd "$(dirname "$0")/../project"
node -e 'const a=process.versions.node.split(".").map(Number);if(a[0]<22||(a[0]===22&&a[1]<5)){console.error("需要 Node >= 22.5.0，当前 "+process.version);process.exit(1)}console.log("Node "+process.version+" OK")'
npm install --no-audit --no-fund
npm --prefix frontend install --no-audit --no-fund
npm run build
echo "完成。启动：cd project && npm run mock (终端A) ; npm run start (终端B) ; 打开 http://127.0.0.1:8787/admin"
```

### 2.2 `readme/install.ps1`（Windows 一键版）

```powershell
# 在作品包根目录执行（ExecutionPolicy 绕过仅对本次进程生效）
powershell -ExecutionPolicy Bypass -File readme\install.ps1
```

脚本与 `install.sh` 等价：校验 Node ≥ 22.5 → 安装后端与前端构建依赖 → `npm run build`。
若不想执行脚本，也可在 `project/` 下手动执行：

```powershell
cd project
npm install --no-audit --no-fund
npm --prefix frontend install --no-audit --no-fund
npm run build
```

## 3. 安装后用 Mock 零密钥复现

```bash
cd project
npm run mock     # 终端 A：本地 mock 上游（离线、零成本）
npm run start    # 终端 B：启动网关（默认 127.0.0.1:8787）
# 或一键 Demo：bash demo.sh（自动起 mock+网关并跑 5 项自检）
```

浏览器打开 `http://127.0.0.1:8787/admin`。

## 4. 组合方案：再起工作台 CodeLens（可选）

底座起来后，应用层工作台可直接源码运行（开发模式，两个终端）：

```bash
cd project/codelens/server && npm install && npm run dev   # :8080
cd project/codelens/client && npm install && npm run dev   # :5173，/api 代理到 8080
# 打开 http://localhost:5173 → 设置里选 provider / 填自己的 Key
```

生产模式（单端口，由 Express 托管 Vite 构建产物）：

```bash
cd project/codelens/client && npm install && npm run build
cd ../server && npm install && npm run build
rm -rf dist-client && cp -r ../client/dist dist-client
npm start        # http://localhost:8080
```

> 演示实例的部署形态是 `8789`（CodeLens 本体，仅本机）+ `8788`（nginx，Basic Auth + CSP 覆盖），
> 完整步骤、配置项与三个上线真坑见 **`readme/组合方案部署说明.md`**。
