# 开源组件说明

> api-relay 承诺：**运行时零第三方依赖**。以下所有组件均为开发期工具或开发依赖，不进入运行时链路。

## 1. 运行时依赖：无

`package.json` 的 `dependencies` 字段为空（或不存在）。网关只用 Node.js 内置模块：

| 内置模块 | 用途 |
|---|---|
| `node:http` | HTTP 服务器与客户端 |
| `node:crypto` | SHA-256 密钥指纹（带域前缀防彩虹表） |
| `node:sqlite`（Node 22.5+） | 控制面存储（WAL 模式） |
| 全局 `fetch` | 上游调用 |

**收益**：供应链攻击面为零；`npm audit` 永远干净；部署只需一个 Node 二进制。

## 2. 开发依赖（devDependencies，共 3 个）

| 组件 | 版本 | 许可 | 用途 |
|---|---|---|---|
| typescript | 5.6 | Apache-2.0 | 编译到 ESM（strict 模式） |
| @types/node | 最新 | MIT | Node 类型定义 |
| tsx | 4.x | MIT | 开发期直接跑 TS（不进产物） |

## 3. 前端构建依赖（frontend/devDependencies，不进运行时）

| 组件 | 许可 | 用途 |
|---|---|---|
| preact | MIT | 3KB React 替代，UI 框架 |
| @preact/signals | MIT | 响应式状态（面板秒级刷新） |
| vite | MIT（含 BSD/ISC 传递） | 构建工具，产物为纯静态文件 |
| typescript | Apache-2.0 | 前端类型检查 |

前端构建产物 `dist-admin/` 为纯静态 HTML/JS/CSS，由 Node 内置 http 直接托管，**运行时同样零框架依赖**。

## 4. 测试框架：Node 原生

`node --test`（Node 18+ 内置），无 jest/vitest/mocha。505 项单测 + 40 项真实进程 E2E 冒烟检查全部基于原生框架与标准 fetch/curl 断言。

## 5. 运维脚本依赖（可选，生产环境）

| 工具 | 用途 | 是否必需 |
|---|---|---|
| curl | 健康检查/冒烟 | Demo 模式不需要 |
| sqlite3 CLI | 数据库一致性备份 | 可选（脚本有 node:sqlite 降级路径） |
| cloudflared / tailscale | 公网隧道 | 仅生产对外暴露时 |

## 6. 许可合规声明

- 本项目**未 fork 任何 AGPL 项目**（刻意避开 NewAPI 等 AGPL 网关）
- 所有依赖许可均为 MIT / Apache-2.0 / BSD 系，允许商用闭源
- 无任何嵌入式二进制或来源不明代码
