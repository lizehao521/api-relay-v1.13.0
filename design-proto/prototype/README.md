# api-relay · 高保真 HTML 原型（阶段3 交付物）

> 单文件、hash 切页、零 CDN、双击即可离线打开的静态高保真原型。
> 设计系统：**Linear 基因 + 沿用 GitHub 暗色色值**（`design-proto/02-design-system.md` v1.0）
> 规格依据：`design-proto/03-prototype-spec.md`（页面结构 / 交互 / 状态 / 权限 / 计费 / 密钥路由 / 监控日志 / 验收）

---

## 1. 如何打开

- **直接双击** `design-proto/prototype/index.html`，用任意现代浏览器（Chrome / Edge / Firefox）打开即可。
- 无需服务器、无需联网、无需构建。**断网可用**（所有 CSS/JS/图标内联，图标为文本符号）。
- 顶部有「角色预览」下拉，可切换 owner / sre / finance / auditor / client 五种视角。

## 5. 可交互 vs 静态示意（给质量审查官）

### ✅ 真实可交互（原型中可点、可见反馈）

1. **hash 路由切页**：点侧栏 / `data-goto` 按钮 / 改 URL hash 均切换页面，刷新停留原页。
2. **角色切换**（顶栏下拉）：切换导航（运营面 ↔ 客户面）、密度（compact ↔ cozy）、动作禁用态（如 sre 不可批准；owner-only 按钮隐藏）。
3. **主题切换**（`◐`）与**密度切换**（`▤`）：全站令牌联动。
4. **抽屉**：`data-drawer` 打开；`Esc` / 点遮罩 / `✕` / `data-close` 关闭；关闭后焦点**归还**触发按钮。
5. **一次性明文**（I1）：新建 / 批准签发 / 轮换后显示明文 + 指纹 + 接入包，关闭后不可再查看。
6. **轮换两步确认**（I2）：勾选"我知道旧 key 会立即失效"才可点确认（未勾选 disabled）。
7. **审批流**（I3）：队列状态 Tabs 过滤；抽屉内批准 / 拒绝（理由必填）/ 部分批准；`sre` 角色批准按钮 disabled。
8. **批量批准**（I15）：勾选计数、全选、汇总提示。
9. **粘贴自检 whoami**（I8）：输入 → 行内 loading → 四态结论（有效 / 已禁用 / 已过期 / 非本网关签发），色 + 文字。
10. **筛选与搜索**：密钥 / 租户 / 审计表按状态筛选 + 关键字过滤。
11. **路由维度切换**（I16）与**优先级上/下移**（I11 键盘兜底）：重排并提示"未保存"。
12. **导出**（I7）：生成 CSV（BOM + CRLF）/ JSON 并触发下载；各页 `导出` 按钮可用。
13. **复制**：`data-copy` 按钮走 Clipboard API，失败降级 `execCommand`，再失败 Toast。
14. **Toast**：所有操作有语义色反馈（`.g/.y/.r`）。
15. **模型清单加载**（`#/docs`）：骨架 → 阶梯名列表（本地模拟）。
16. **90 天可用性条 / 时钟 / 数据新鲜度**：动态生成 / 实时。
17. **死交互已消除（P1-2 修复）**：`#/keys` 启用、`#/users` 重置额度、`#/ch` 摘除/清熔断、`#/plans` 编辑/下架（开抽屉）、`#/billing` 通知/提额/停用，以及 `#portal-win`/`#usage-period`/`#ov-win`/`#nf-win`/`#nf-int` 选择器，均已接入事件委托并给出 Toast/抽屉/联动反馈。
18. **抽屉焦点锁定（P1-3 修复）**：打开时 `#shell` 与移动遮罩置 `inert` + `aria-hidden`，`Tab`/`Shift+Tab` 在抽屉内**首尾回环**；关闭时还原并**焦点归还**触发元素。
19. **可点击行键盘可达（P1-3 修复）**：`#/ledger` 行首改为 `.row-act` **真实按钮**撑满整行（`aria-label` 播报 + `:focus-visible` 焦点环），键盘/屏读可用。
20. **导航重排提示 + 旧顺序开关（AC-05 修复）**：`#/ov` 顶部可关闭提示 + 「按旧顺序查看」双态切换（新：值守/经营/客户/系统 ↔ 旧：监控/配置/智能/系统），选择持久化到 localStorage。
21. **表格首载骨架 + 空态（P2-7）**：`#/keys`/`#/users`/`#/audit` 表格首载显示骨架行 420ms；`#/keys` 搜索/筛选无结果显示 `Empty`（⚑）；`#/audit` 对受限角色显示 ⛔ 403 示例。
22. **SDK 复制（P2-1）**：`#/docs` 复制按钮按 `data-copy-sel` 取 `#sdk-code` 的正文复制。
23. **错误 Toast 无障碍（P2-2）**：错误 Toast 设 `role="alert"` + `aria-live="assertive"`。

### 改进方案落地（v1.1 · 纳入 2026-10-24 已批准的竞品/路线图改进）

24. **归因契约对外公开（改进项1）**：`#/diag` 新增 15 类 `failure_reason` × 11 种 `quick_action` × OpenRouter `error_type` 词表（含契约 JSON `api-relay.attribution.v1`，可一键复制）。

### 🟡 静态示意（占位数据，标注"示意 / 占位待替换"）

1. **全部数值**（请求数 / Token / 成本 / 毛利率 / SLO 值 / 延迟）为**假数据示意**，仅用于展示字段与布局——**不构成任何真实承诺或统计断言**。
2. **套餐定价**：因阶段1 M2（真实定价）缺失，套餐卡金额与账单牌面价为**占位**，页内已标注"占位待替换"。
3. **图表**：总览柱图、可观测折线为骨架/色块占位（非真实绘图库）。
4. **告警动作 / 通知渠道**：按阶段1 Q10，仅表达入口，UI 标注"通知渠道待接入"。
5. **红点 / 计数徽标**（如审批 `3`）为固定示意值。
6. **登录门**：原型默认已登录，未实现 `#/login`（阶段1 现状为单一 `X-Admin-Token`）。

## 6. 无障碍与约束自检

- **零依赖**：无 CDN、无 `@import url()`、无图标字体；图标为文本符号（`▦ ∿ ☰ ⚑ ◆ ⧗ ▤ ⇄ ⬡ ¥ ◉ ▷ ⚙ ⚖ ✓`）。
- **键盘**：`:focus-visible` 焦点环；`Esc` 逐级关闭（抽屉 → 移动侧栏）；抽屉打开焦点移入、关闭归还。
- **不靠色**：状态/进度均"色 + 符号/文本"双编码（`●▲■◆○`、百分比）。
- **数字列**：`tabular-nums` + 右对齐 + 等宽字体（`.num`）。
- **响应式**：≤1020px 两栏折列 / KPI 折 2 列；≤960px 侧栏收进抽屉；≤720px 单列 + 触控目标加大。
- **动效**：仅 CSS transition/animation，`prefers-reduced-motion: reduce` 下全局关停。
- **红线**：界面**无**任何"改写成功响应 / 缓存 / 去重 / Agent 编排平台"的暗示；透明信息（`X-Relay-Mode` / `x-relay-model-*`）可见。
