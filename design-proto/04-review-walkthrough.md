## 2. D1 · 浏览器兼容实测

| 项 | 检查点 | 期望 | 结论 | 证据 |
|---|---|---|---|---|
| `inert` | 打开任一抽屉，背景 `#shell` 置 `inert`（原型 L1983–1986 区域） | 背景不可 Tab 聚焦、不可点击；无 `inert` 支持时仍屏蔽背景点击 | ☐ | |

| 主题/密度 | 顶栏 `◐`（主题）、`▤`（密度） | 全站令牌联动，无残留硬编码色 | ☐ | |
| 响应式断点 | 缩窗至 ≤1020 / ≤960 / ≤720 | 折列 / 侧栏抽屉 / 单列 + 触控加大 | ☐ | |

| 项 | 检查点 | 期望 | 结论 |
